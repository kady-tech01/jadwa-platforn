# 📊 Jadwa Platform - Financial Feasibility & Data Analysis

An end-to-end full-stack web application designed for automated financial feasibility studies, cash flow forecasting, sensitivity analysis, and risk assessment.

## 🛠️ Tech Stack
- **Backend:** Python, Django REST Framework, Pandas, NumPy
- **Frontend:** React.js (Web Application)
- **Database:** MariaDB
